# Courses Project

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/XanderWhite/courses.git .
git checkout -b xander origin/xander

# Backend (Laravel)
cd backend/
composer install
# Настроить .env файл

# Frontend (React)
cd frontend/
npm install

# Запуск
cd frontend/
npm start

cd backend/
php artisan serve
